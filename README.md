# Retail Profitability Analysis

An R-based analysis of how retail sales, discounts, and costs affect profitability. The project asks where sales volume translates into profit and where discounting can erode margins.

## Analysis

The analysis examines profitable and unprofitable transactions, compares results across discount levels, and uses pricing scenarios to explore potential changes in profit. Scenario estimates describe modeled outcomes.
